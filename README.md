# Phoenix AI 🔥

A Telegram bot that reads any PDF document 
and answers questions about it instantly.

## What It Does
- Send any PDF to the bot
- Ask any question about it
- Get instant intelligent answers
- Powered by advanced AI

## Built With
- Python
- Groq API (LLaMA 3.3 70B)
- Telegram Bot API

## Try It
Search @your_bot_username on Telegram
